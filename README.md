Custom Adreno 640 GPU driver for Snapdragon 855/860 (Magisk/KernelSU). 
Features Vulkan 1.1, OpenGL 3.2, and OpenCL 3.0 with bootloop prevention, smart shader cleaner, and strict SELinux rules for maximum gaming performance.
